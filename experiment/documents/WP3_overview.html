WP3 — Belief Updating

Adaption von Rollwage, Dolan & Fleming (2018) auf die Control Detection Task (CDT) · Online-Studie, N ≈ 150 (Prolific/Pavlovia)

Die Grundfrage

Wenn Menschen nach einer Entscheidung neue Evidenz bekommen — revidieren sie ihre Überzeugung rational, oder gewichten sie widersprechende Evidenz systematisch schwächer (Confirmation Bias)?

Und: Ist dieser Bias stärker, wenn das Urteil auf einem festen internen Vorhersagemodell beruht (0°) als wenn es flexibel aus Regelmäßigkeiten erschlossen wird (90°)?

Die Basisaufgabe: Control Detection Task

Schwierigkeit = Kontrollanteil prop. Eine 1-up-2-down-Staircase kalibriert auf 70,7 % korrekt — der Punkt maximaler Unsicherheit, an dem neue Evidenz das Urteil noch verschieben kann.

Zwei Verarbeitungsmodi (geblockt, Reihenfolge counterbalanced)

0° — Prädiktion

Die Form folgt der Maus direkt. Man vergleicht die Bewegung mit dem eigenen festen internen Vorhersagemodell.

90° — Regularität

Die Bewegung ist um 90° rotiert — das Vorhersagemodell versagt, man muss das Muster flexibel entdecken.

Das Ganze × 2 Winkel ≈ 280 Trials, ~50–55 min. Der einzige Unterschied zwischen Task 1 und 2: wann Confidence abgefragt wird.

Der Kernmechanismus: das Post-Decision-Evidence-Sample

In Task 2 wird nach der Entscheidung die Bewegung noch einmal 3 s gezeigt (keine Antwort möglich) — und zwar immer mit dem wahren Target, unabhängig von der Wahl.

Richtig entschieden

Sample bestätigt die Wahl → Confidence sollte steigen.

Falsch entschieden

Sample zeigt auf die andere Form → widerlegt → Confidence sollte sinken.

⚠️ Wichtig: Die Proposal-Formulierung „for the object they have chosen" wäre wörtlich genommen ein Designfehler — dann wäre jedes Sample bestätigend. Korrekt (wie bei Rollwage): Evidenz zeigt immer auf die Wahrheit.

Was gemessen wird

MaßBedeutung
Confirmatory βAnstieg der Confidence über Evidenz-Level auf korrekten Trials
Disconfirmatory βAbfall auf inkorrekten Trials (vorzeichengedreht) — wie stark revidiert wird
meta-d′Metakognitive Sensitivität, aus Task 1

Confirmation Bias = disconfirmatory β < confirmatory β. Kein Trial-Pairing über Phasen — jeder Trial geht als eigener Datenpunkt in eine gepoolte Regression confidence ~ level ein.

Hypothesen

  1. Asymmetrie: Bestätigende Evidenz wird stärker gewichtet als widerlegende.
  2. Modus-Effekt (Kernhypothese): Der Bias ist im Prädiktionsmodus (0°) stärker als im Regularitätsmodus (90°).
  3. Klinische Brücke: Höhere Delusional Ideation (PDI, extern erhoben) → mehr Resistenz gegen widerlegende Evidenz, v. a. bei 0°.
