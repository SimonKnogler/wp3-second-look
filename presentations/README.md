# Presentations

Slide decks and talk material for WP3. Add your own files here.

## Already available in `experiment/documents/`

| File | What it is |
|---|---|
| `WP3_briefing.pdf` | 14-page project briefing, continuous prose + all figures. Good source material if you want a generative tool to draft slides. |
| `WP3_lab_talk.html` | 20-slide lab talk. Open in a browser: `→`/`space` next, `←` back, `F` fullscreen, `D` dark/light, `?` help. Prints to PDF one slide per page. |
| `WP3_lab_talk_short.html` | 10-slide version — framing through hypotheses, no predicted-data section. |
| `WP3_hypothesen.html` | Long-form visual walkthrough of the design and the predicted patterns. |
| `figures/` | All 13 figures as PNG, 2800 px wide, white background. `figures/README.txt` describes each one. |

## Conventions

- Name files `YYYY-MM-DD_venue_topic.pdf`, e.g. `2026-10-14_labmeeting_second-look.pdf`.
- Keep the source file (`.pptx`, `.key`, `.html`) next to the exported PDF where possible.
- Figures marked **SIMULATED** show model predictions, not collected data — keep that
  label on any slide that reuses them. No human data exist yet.
